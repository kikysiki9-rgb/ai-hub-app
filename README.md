
Лёгкий и быстрый мобильный ИИ-агрегатор для Android, собранный в одном HTML-файле на базе Capacitor. Работает по принципу **BYOK (Bring Your Own Key)** — вы сами добавляете свои API-ключи, и они хранятся только на вашем устройстве.

> ⭐ **Понравился проект? Поставь звёздочку (Star) в правом верхнем углу — это очень помогает развитию приложения!**

---

## ✨ Возможности

* **Поддержка топовых моделей:** ChatGPT (GPT-6.2 Astra / Sol / Luna), Claude (Sonnet 5) и любые OpenAI-совместимые шлюзы (OpenRouter и др.).
* **⚔️ Баттл моделей:** сравнивайте ответы разных нейросетей на один и тот же запрос.
* **🎭 Профили и характеры:** настраивайте системные промпты или выбирайте готовые пресеты (Сеньор-разработчик, Дерзкий ассистент, Переводчик и др.).
* **🔒 Безопасность и автономность:** никаких серверов-посредников — ключи хранятся локально в приложении с поддержкой резервного копирования (бэкапов).
* **📊 Прозрачный расход:** отображение коэффициентов стоимости для каждой модели.

---

## 📥 Установка на Android

1. Перейдите в раздел **[Releases](https://github.com)** справа (или внизу страницы с телефона).
2. Скачайте актуальный файл **`app-debug.apk`**.
3. Установите APK на смартфон.
4. Откройте приложение, нажмите **🔑 Ключ**, вставьте свой API-ключ (и при необходимости Base URL) — готово!
