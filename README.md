# 🧠 AI Hub — Мобильный ИИ-агрегатор для Android

Лёгкий, быстрый и автономный мобильный ИИ-агрегатор для Android, собранный в одном HTML-файле на базе Capacitor. Работает по принципу **BYOK (Bring Your Own Key)** — вы сами добавляете свои API-ключи, и они хранятся только на вашем устройстве, без серверов-посредников.

> ⭐ **Нравится проект? Поставь звёздочку (Star) — это очень помогает развитию!**

## ✨ Основные возможности

- **Поддержка топовых моделей ИИ**
  - Claude (Fable 5.2, Opus 5.5, Sonnet 5.5, Haiku 5.5)
  - ChatGPT (GPT-6.2 Astra / Sol / Luna)
  - Gemini (4 Argon, 3.8 Flash, 3.6 Flash)
  - DeepSeek, Grok, Qwen, Kimi, NVIDIA Nemotron, MiniMax, Xiaomi Mimo
  - Любые OpenAI-совместимые API-шлюзы (OpenRouter и другие)

- **⚔️ Баттл моделей**
  - Сравнивайте ответы разных ИИ на один запрос в реальном времени
  - Выбирайте лучший результат

- **🎭 Профили и системные промпты**
  - Настраивайте поведение моделей через системные промпты
  - Встроенные пресеты: «Сеньор-разработчик», «Переводчик», «Дерзкий ассистент», «Кратко и по делу»
  - Персональный контекст для каждого разговора

- **🧠 Расширенное мышление (Reasoning)**
  - Поддержка режимов мышления (Low, Medium, High, Max) для моделей, которые это поддерживают
  - Просмотр хода рассуждений ИИ перед финальным ответом
  - Визуализация процесса мышления

- **📸 Работа с изображениями**
  - Прикрепляйте фотографии к сообщениям
  - Поддержка моделей с vision-возможностями
  - Встроенный предпросмотр изображений

- **🔒 Безопасность и приватность**
  - **Никаких серверов-посредников** — все взаимодействие напрямую с API провайдеров
  - Ключи хранятся **только локально** на вашем устройстве
  - Поддержка резервного копирования (backup) конфигурации
  - Возможность экспорта/импорта ключей через коды доступа
  - Поддержка настраиваемых Base URL

- **🤖 Режим автономного агента** (опционально)
  - GitHub интеграция: чтение репозиториев, анализ кода, автоматические исправления
  - Tool Calling для запросов моделей, которые это поддерживают
  - Автопочинка GitHub Actions (максимум 3 попытки)

- **📊 Прозрачный расход**
  - Отображение коэффициентов стоимости для каждой модели
  - Слежение за используемыми токенами

- **💬 Удобный интерфейс**
  - Тёмная тема с градиентом
  - Поддержка safe-area для notch и gesture-bar
  - Плавные анимации и переходы
  - History of conversations с быстрым переключением между чатами

## 📥 Установка на Android

### Способ 1: Скачивание APK (быстро)

1. Перейдите на страницу **[Releases](https://github.com/kikysiki9-rgb/ai-hub-app/releases)** (справа, или внизу на мобильном)
2. Скачайте актуальный файл **`app-debug.apk`**
3. Перейдите в файловый менеджер, найдите скачанный APK и нажмите на него
4. Разрешите установку из неизвестных источников (если система попросит)
5. Установленное приложение появится в главном меню

### Способ 2: Сборка с исходников

```bash
# Клонируем репозиторий
git clone https://github.com/kikysiki9-rgb/ai-hub-app.git
cd ai-hub-app

# Установим зависимости
npm install

# Собираем для Android
npx cap add android
npx cap sync android
npx cap build android
```

Готовый APK будет в `android/app/build/outputs/apk/debug/`.

## 🔧 Быстрый старт

### 1. Первый запуск

1. Откройте приложение
2. В верхнем правом углу нажмите **🔑 Ключ**
3. Добавьте ваш API-ключ (например, от Claude или ChatGPT)
4. При необходимости укажите собственный **Base URL** (для OpenRouter, собственного прокси и т.д.)
5. Нажмите **Сохранить**

### 2. Выбор модели и профиля

- Нажмите на **текущую модель** в верхней части экрана, чтобы выбрать другую
- Нажмите **👤 Профиль**, чтобы установить системный промпт (выберите пресет или введите свой)
- Используйте **⚔️ Баттл моделей** для сравнения двух ИИ

### 3. Отправка сообщения

1. Введите текст в поле снизу
2. Нажмите **➤** или Enter
3. Дождитесь ответа

**Дополнительные опции:**
- **📎** — прикрепить изображение (если модель поддерживает vision)
- **🧠** — включить режим расширенного мышления
- **☰** — история чатов

## 🔐 Безопасность и конфиденциальность

### Как хранятся ключи?

- **Локально**: Все ключи сохраняются в `localStorage` вашего браузера / приложения
- **Не передаются на сторону**: Все API-запросы идут напрямую от вашего девайса к API провайдерам
- **Шифрование**: Рекомендуется использовать экран блокировки девайса

### Рекомендации по безопасности

1. **Fine-grained tokens**: Если используете GitHub интеграцию, создавайте fine-grained токены с доступом только к нужному репозиторию
2. **Ограничение прав**: Дайте токену минимальные права: `Contents (read)`, `Actions (read)`, `Metadata`
3. **Лимиты**: Установите лимиты на использование API в своём аккаунте провайдера
4. **Резервное копирование**: Экспортируйте коды доступа к ключам и храните в безопасном месте
5. **Удаление**: Если потеряли телефон, удалите скомпрометированные ключи в интерфейсе провайдера

## 🤖 Режим автономного агента (GitHub Integration)

Когда активирован, режим позволяет ИИ:

- **Читать файлы** из GitHub репозитория
- **Анализировать код** через поиск по тексту
- **Просматривать историю** commits и Actions логи
- **Исправлять ошибки** автоматически (максимум 3 попытки)

### Как включить?

1. Нажмите **🔧** (Интеграции)
2. Вставьте GitHub PAT (Personal Access Token)
3. Укажите целевой репозиторий (`username/repo-name`)
4. Включите ☑️ **Режим автономного агента**
5. Нажмите **Проверить токен** или **🛠 Автопочинка Actions**

### Требуемые права токена

```
✅ Contents: read (чтение файлов)
✅ Actions: read (просмотр логов Actions)
✅ Metadata: read (получение информации о репо)
❌ Не нужны: write права на основном репо (используйте fine-grained!)
```

## 🎨 Настройка и персонализация

### Системный промпт (Профиль)

Нажмите **👤 Профиль** и выберите / создайте свой промпт:

- **💻 Сеньор-разработчик** — ориентация на код и best practices
- **⚡ Кратко и по делу** — лаконичные ответы без лишнего
- **🌍 Переводчик** — специализация на переводах
- **😈 Дерзкий ассистент** — неформальный, немного провокационный тон

**Или введите свой текст** для полной кастомизации.

### Расширенное мышление

Если модель поддерживает reasoning:

1. Нажмите **🧠** внизу для включения
2. Выберите уровень: **Low, Medium, High, Max**
3. Смотрите **хід рассуждений** в отдельной секции перед ответом

### Собственные ключи и URL

В **🔑 Ключ**:

- **API Key**: Скопируйте из личного кабинета провайдера
- **Base URL** (опционально): Если используете OpenRouter, собственный прокси или другой API-шлюз

Пример для OpenRouter:
```
Base URL: https://openrouter.ai/api/v1
Key: sk-or-...
```

## 🐛 Решение проблем

### Приложение медленно загружается

- Убедитесь, что у вас хорошее интернет-соединение
- Очистите кеш: **Settings → Apps → AI Hub → Storage → Clear Cache**
- Переустановите приложение

### Ключ не работает

1. Проверьте, что ключ **не истёк** в кабинете провайдера
2. Убедитесь, что ключ имеет **нужные права/scopes**
3. Нажмите **🔄 Проверить токен** для диагностики
4. Попробуйте переустановить ключ

### Ошибка при отправке сообщения

```
Ошибка: 401 Unauthorized
  → Ключ истёк или некорректен

Ошибка: 429 Too Many Requests
  → Лимит API исчерпан, подождите

Ошибка: 500 Internal Server Error
  → Проблема с провайдером, повторите позже
```

### Баттл моделей не работает

- Убедитесь, что **обе модели** имеют активные ключи
- Проверьте, что у **Model B выбрана другая модель**, чем Model A

### GitHub интеграция не подключается

1. Проверьте, что токен **fine-grained** или **classic** с правами `repo`, `read:org`
2. Убедитесь, что **репозиторий доступен** токену
3. Нажмите **🔄 Проверить токен** для диагностики
4. Если всё не работает, создайте новый токен с нуля
