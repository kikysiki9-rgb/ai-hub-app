# ✨ AI Hub

**Один интерфейс для общения с разными ИИ‑моделями, сравнения ответов и работы с GitHub.**

AI Hub — русскоязычный веб‑клиент, который можно открыть в браузере или собрать в Android‑приложение на Capacitor. В репозитории нет отдельного бэкенда: клиент обращается к настроенным API напрямую. Для ответов модели нужны собственный API‑ключ, адрес совместимого API и интернет.

| 🐙 **Интеграция с GitHub** | Просматривай структуру репозитория, читай файлы, ищи по коду и разбирай логи GitHub Actions прямо из чата. |

<a id="quick-start"></a>
## ⚡ Быстрый старт в браузере

Установи Git и Python 3. Для веб‑версии не требуются `npm install` и отдельная сборка фронтенда: достаточно раздать каталог `www` локальным HTTP‑сервером.

// filepath: README.md
```bash
git clone https://github.com/kikysiki9-rgb/ai-hub-app.git
cd ai-hub-app
python3 -m http.server 8000 --directory www --bind 127.0.0.1
```

Открой <http://127.0.0.1:8000>. На Windows вместо `python3` можно использовать `py -3`, если установлен Python Launcher.

### 🔑 Как подключить модель

1. Нажми на название модели в верхней панели и выбери нужную модель.
2. В меню **«Ключи»** добавь конфигурацию для её группы: имя, API‑ключ и **Base URL** по документации твоего сервиса.
3. При необходимости измени **слаг модели** — идентификатор, который принимает сервер. Название модели в интерфейсе может отличаться от идентификатора в API.
4. Убедись, что выбран нужный ключ, и отправь короткий запрос, например: «Ответь одним предложением: что такое Capacitor?»

> **Важно:** Base URL — базовый адрес API, а не адрес веб‑чата. Проверка ключа и отображение баланса зависят от доступных эндпоинтов сервиса. Счётчик в AI Hub локальный: для фактических списаний сверяйся с кабинетом провайдера.

<a id="github-integration"></a>
## 🐙 Работа с GitHub

В **«Интеграциях»** можно указать токен GitHub и репозиторий в формате `owner/repo`. Для чтения собственного репозитория начни с fine‑grained токена, ограниченного выбранным репозиторием, с правами чтения `Contents` и `Actions` (и доступом к `Metadata`). Проверка токена в интерфейсе подтверждает вход, но не гарантирует доступ к каждому репозиторию или операции.

| Режим чата | Когда использовать |
| --- | --- |
| **Авто** | Приложение по формулировке определяет, обычный это вопрос или задача про GitHub. |
| **Чат** | Когда нужен ответ модели без работы с выбранным репозиторием. |
| **GitHub** | Когда нужно явно работать с репозиторием: например, изучить структуру или разобрать логи сборки. |

Примеры запросов:

- «Покажи дерево репозитория и объясни, где находится точка входа».
- «Прочитай workflow сборки и объясни, как из него получается APK».
- «Разбери последний сбой Actions и предложи исправление, ничего не меняя».

**Режим агента** добавляет возможности записи. В интерфейсе также есть автопочинка Actions с максимум тремя попытками. Для анализа оставляй режим записи выключенным и используй токен только для чтения. Если нужны изменения, работай на тестовом репозитории и проверяй получившиеся коммиты и статус сборки. Кнопка быстрого создания репозитория создаёт **публичный** репозиторий.

### 🌐 Интернет‑поиск

Переключатель **🌐** даёт доступ к внешнему поиску и поиску по GitHub. В интеграциях можно задать необязательный ключ **Jina Reader**. Поисковые запросы и адреса страниц могут отправляться в GitHub, Stack Exchange, Hacker News и `r.jina.ai`. Не включай в запросы пароли, токены, закрытые ссылки или приватный код.

<a id="android-build"></a>
## 📱 Android: скачать или собрать APK

### 📦 Скачать из GitHub Actions

1. Открой workflow [**Build APK**](https://github.com/kikysiki9-rgb/ai-hub-app/actions/workflows/build.yml).
2. Выбери успешный запуск. Если свежей сборки нет и у тебя есть права на запуск, нажми **Run workflow**.
3. Внизу страницы запуска, в разделе **Artifacts**, скачай `app-debug`.
4. Распакуй архив и установи `app-debug.apk` на Android. Если система попросит разрешить установку из этого источника, делай это только для APK из доверенной сборки.

Это **debug‑сборка** для тестирования, не релиз для Google Play. Для скачивания артефакта нужно войти в GitHub; старые артефакты могут быть уже удалены.

### 🛠️ Собрать локально

Понадобятся **Node.js 20**, **JDK 17** и настроенный **Android SDK** (удобно установить через Android Studio). Версии Node.js и Java соответствуют текущему workflow. Из корня репозитория:

// filepath: README.md
```bash
npm install
npx cap add android
npx cap sync android
cd android
chmod +x gradlew
./gradlew assembleDebug
```

На Windows вместо двух последних команд используй `gradlew.bat assembleDebug` (`.\gradlew.bat assembleDebug` в PowerShell). `npx cap add android` нужен только при первом создании папки `android/`; после правок в `www/` повтори `npx cap sync android` из корня проекта и пересобери APK.

**Результат:** `android/app/build/outputs/apk/debug/app-debug.apk`.

**Как устроен CI:** пуш в `main` или ручной запуск → Node.js 20 и Temurin 17 → `npm install` → создание и синхронизация Android‑проекта → `assembleDebug` → загрузка артефакта `app-debug`.

## 🗂️ Структура репозитория

| Путь | Назначение |
| --- | --- |
| [`www/index.html`](www/index.html) | Веб‑интерфейс, стили и JavaScript: чат, каталог моделей, настройки ключей и внешние интеграции. |
| [`capacitor.config.json`](capacitor.config.json) | Конфигурация Android‑обёртки: имя `AI Hub`, идентификатор `com.aihub.app`, веб‑каталог `www` и включённый `CapacitorHttp`. |
| [`package.json`](package.json) | Зависимости Capacitor 6: `core`, `android` и `cli`. |

**Стек:** HTML, CSS и JavaScript без фронтенд‑фреймворка, Capacitor, Android Gradle и GitHub Actions. Шрифт Inter и JSZip подключаются с внешних CDN. Папка `android/` генерируется при сборке и не хранится в репозитории.

<a id="privacy"></a>
## 🔒 Конфиденциальность и ключи

- **История, настройки и секреты хранятся в `localStorage`** браузера или WebView без прикладного шифрования. Не используй постоянные ключи с широкими правами на общем устройстве. Очистка данных сайта или приложения удаляет локальную историю и настройки.
- **Ответы генерируются удалённо.** Текст чата и вложения отправляются на настроенный API, а при работе с GitHub в контекст модели могут попадать прочитанные файлы и логи. Перед отправкой проверь, допустимо ли передавать эти данные выбранному сервису.
- **Коды `aihub-key://…` не зашифрованы.** Обладатель кода может извлечь ключ и использовать его напрямую. Локальный лимит в AI Hub не заменяет серверный лимит у провайдера.
- Не коммить секреты и не вставляй их в задачи, логи или скриншоты. Если ключ стал доступен посторонним, отзови его у провайдера и выпусти новый.

## 🧯 Решение частых проблем

| Симптом | Что проверить |
| --- | --- |
| API отвечает `401` или `403` | Активный ключ, Base URL, доступ ключа к выбранной модели и ограничения аккаунта. Для GitHub также проверь доступ токена к нужному репозиторию и разделу Actions. |
| Модель не найдена | Сверь слаг с каталогом твоего API, а не только с названием в AI Hub. |
| Браузер сообщает об ошибке CORS | Проверь, разрешает ли API запросы с адреса локальной страницы. В Android используется `CapacitorHttp`, поэтому сетевое поведение может отличаться. |
| На фото модель не отвечает | Убедись, что файл не превышает 4 МБ, а API и модель поддерживают изображения. |
| В баттле отвечает только одна модель | Проверь ключ, Base URL и доступность слага отдельно для каждой модели. |
| После изменений APK показывает старый интерфейс | Сначала выполни `npx cap sync android`, затем пересобери APK и переустанови его. |
| Нет артефакта `app-debug` | Проверь, что запуск дошёл до шага загрузки артефакта и срок хранения ещё не истёк. |

## 🤝 Как предложить изменения

Создай ветку, внеси правки и открой pull request. Для изменений интерфейса приложи скриншот или короткие шаги воспроизведения. Перед отправкой проверь запуск в браузере; если изменение касается Android — также собери debug APK. Не добавляй в коммит `node_modules/`, сгенерированную папку `android/`, APK или секреты.
